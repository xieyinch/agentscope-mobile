## 原生化次序

1. 先依据官方开源代码/文档确认认证与 API 契约，明确平台部署 API 与实例控制台 API 的边界，不猜测接口。
2. 实现会话流、停止生成、工具审批、历史记录与多智能体切换。
3. 实现模型、技能、工具、MCP/ACP、频道、定时任务及运行配置。
4. 实现终端、文件、用量、备份、日志与部署管理。
5. 社区原生化；逐项对照网页版和真机操作验收后，才将对应状态标为完成。

## 必须覆盖的验收

- 登录持久化、失效重登录、退出与跨页账户一致性。
- Open QWENPAW 新窗口、返回、关闭、切换栏目防止误丢表单。
- 文件上传、下载、长对话流式输出、网络中断与重连。
- 终端组合键、软键盘与横竖屏；模型配置保存失败不得提示成功。
- 删除、重置与升级需明确目标及后果；不得读取并上传用户配置作为测试数据。
- Android 8/12/14/15 真机安装与兼容性。
