## 验收要求

- 不得用网页入口、静态卡片或模拟数据代替真实功能。
- 每项完成需对照当前部署版本验证：请求结构、成功/失败、数据回读、账户与 Agent 隔离、后台恢复。
- 删除与重置必须确认目标和后果；保存失败不得提示成功。
- 必须在 Android 8/12/14/15 真机验证布局、软键盘、终端、文件权限和安装升级。
- 从官方源码确定路径，不猜测凭据、不提交账户数据。平台与实例的凭据不得互相转发。
